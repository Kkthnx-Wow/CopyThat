One button that copies your chat. Click it and the whole visible window lands in a clean, selectable text box.

## What it does

- Adds a small Copy icon to your chat frame that grabs every visible line at once.
- Flattens links to readable text, strips textures, and preserves message colors.
- Lets you put the icon in any chat-frame corner with adjustable transparency.
- Works across Midnight, The War Within, Cataclysm Classic, and Classic Era.
- Applies every setting live from a native Blizzard options panel.

## Get it

Install from [CurseForge](https://www.curseforge.com/wow/addons/copythat), or download the latest release from the [Releases](https://github.com/Kkthnx-Wow/CopyThat/releases) page and extract the `CopyThat` folder into `World of Warcraft/_retail_/Interface/AddOns`.

## Quick start

1. Install the addon and restart the game, or `/reload`.
2. Hover the chat frame and click the Copy icon.
3. Select the text in the window and copy it with your usual shortcut.
4. Press Escape to close the window.
